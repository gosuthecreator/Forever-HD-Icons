# Forever HD Icons

**Sharper icons for World of Warcraft: Forever — every spell, item and talent at twice the resolution.**

The game's icons were drawn small, and on today's screens they turn soft and blocky on your action bars, in your bags and in every tooltip. Forever HD Icons replaces them with crisp 128×128 versions.

The icons are Blizzard's own artwork, kept faithful to the originals — same shapes, same colours, same transparency — just upscaled with care. Nothing is redrawn or restyled, so every icon still looks exactly like itself, only clearer.

## Features

- **4,801 icons** at 128×128: spells, abilities, items, gear, consumables, professions, achievements, talents and more.
- **Faithful upscaling**: Real-ESRGAN with the 4x-UltraSharp model, then scaled to 128×128 with each icon's own transparency kept.
- **Works everywhere** the game shows an icon: action bars, bags, the spellbook, talents, tooltips, the quest log, loot and more.
- **Works with any interface**: the default UI or any addon. It also sits well with Hearth UI.
- **No performance cost**: the game simply loads these files instead of its own. There is no addon running.
- **Only what Forever uses**: icons referenced by Forever's game data and interface. Anything not included keeps the game's own version.

## Install

This is **not an addon**. It replaces the game's icon files, so it goes in the **Interface** folder, not in AddOns.

1. Close the game completely.
2. From the downloaded zip, copy the **`ICONS`** folder into
   `World of Warcraft\_classic_beta_\Interface\`
   so that you end up with
   `World of Warcraft\_classic_beta_\Interface\ICONS\*.blp`
3. Start the game. A `/reload` is not enough — it must be a full start.

## Uninstall

1. Close the game.
2. Delete the folder `World of Warcraft\_classic_beta_\Interface\ICONS`.
3. Start the game again. The game's own icons are back.

## Updating

Replace the whole `ICONS` folder with the new one, then start the game again.
